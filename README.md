## 3D feature based website

*Tech Stack* : Next.JS, Typescript, Three.JS, lucide-react

This app is a regular scrollable app, with features such as a 3D wave particle grid
where the user can move it around and interact with the 3D grid.

It was an extremely design centric app built, the user can interact with various
elements and feel like they are doing something even though they aren't

## How to run

`git clone https://github.com/Chait314/Algoryx_three`

`npm run dev`
